# Home Credit LAP AI Voice Agent

## Project Overview
This project is an AI-powered voice agent designed to assist existing Home Credit customers interested in a Loan Against Property (LAP).

The agent explains the loan offer, checks basic eligibility, handles callback requests, and directs customers with existing property loans to a specialist.

## Key Features
- Natural voice conversations with customers.
- Customer identity confirmation.
- Busy-customer handling and callback preferences.
- Loan amount handling up to ₹75 lakh.
- Property type and ownership checks.
- Verification of original property documents.
- Occupation and income-mode eligibility checks.
- Loan tenure validation from 3 to 15 years.
- Recognition of information provided out of order.
- Customer corrections and clarifications.
- Specialist handoff for existing property loans or EMI reduction requests.
- Avoids inventing interest rates, EMI amounts, or final loan approvals.

## Eligibility Rules
1. Eligible property types: residential, commercial, and industrial.
2. Agricultural property: not eligible.
3. Sole and joint ownership: both accepted.
4. Original property documents must be available for verification.
5. Maximum requested loan amount: ₹75,00,000.
6. Salaried and self-employed applicants are accepted.
7. Income must be received through a bank account.
8. Property market value is collected without inventing a minimum threshold.
9. Permitted tenure: 3–15 years, inclusive.

## Important Disclaimer
The agent performs preliminary eligibility checks only. Final eligibility, interest rates, EMI calculations, and loan approval must be confirmed by an authorized Home Credit loan expert.

## Implementation
The conversational voice agent was configured and published using Retell AI.

## Testing
The agent was tested against scenarios including:
- Standard eligibility conversation.
- Agricultural property disqualification.
- Cash-income disqualification.
- Unavailable original documents.
- Existing loan and specialist handoff.
- Loan amounts above ₹75 lakh.
- Tenure limits.
- Joint ownership.
- Out-of-order customer information.
- Callback requests.
- Avoiding unsupported financial claims.
- Customer answer corrections.
